# RazorGrowth AI

## Merchant Growth Command Center

RazorGrowth AI converts transaction intelligence into responsible, evidence-based merchant growth opportunities.

## Pipeline

Transaction Data
→ Agent 1 Opportunity Engine
→ Deterministic Ranking
→ Gemini Advisory
→ Merchant Approval
→ Razorpay TEST Execution
→ Audit Trail

## Features

- Deterministic growth opportunity detection
- Gemini AI advisory
- Merchant approval and decline
- Safety and duplicate prevention
- Razorpay TEST payment links
- Audit history
- AI Expected Revenue tracking

## Technology

- Python
- Streamlit
- Google Gemini API
- Razorpay TEST API

## Run

pip install -r requirements.txt

streamlit run app.py

## Security

API keys are stored in .env and should never be uploaded to GitHub.

This project uses Razorpay TEST mode.
